**第1节：AI到底是什么？** 用大白话解释AI的概念，不涉及任何技术术语。用你每天都在用的例子说明，刷抖音的推荐算法、美图秀秀的美颜、手机人脸解锁，这些都是AI。你不需要理解背后的数学原理，只需要知道一件事：你给它一个指令，它能帮你干活。

**第2节：AI发展简史。** 从1956年"人工智能"这个词被第一次提出，到2022年ChatGPT发布，再到2026年国产AI全面开花。用时间线的方式呈现，你只需要记住几个关键节点就行。重点解释为什么2022年是一个分水岭——AI从专业工具变成了普通人也能用的工具。

### Q1：完全没有基础，能学会吗？

**能。** 本教程就是从"你完全没碰过AI"开始的。你把AI想象成一个超级助手就行。你不会做饭？告诉AI你想吃什么，它给你菜谱。你不会写文案？告诉它你想要什么效果，它帮你写。你只需要学会一件事：怎么跟AI说话。

## 附录D：术语表

给完全零基础的读者解释一些你可能会遇到的术语。

**AI（人工智能）：** Artificial Intelligence的缩写，就是让电脑能像人一样思考的技术。

**大模型（Large Language Model，LLM）：** 一种AI技术，通过阅读海量文本学习语言和知识。你现在用的所有AI对话工具都是基于大模型。

**提示词（Prompt）：** 你输入给AI的文字，告诉AI你想要什么。写好提示词是使用AI的核心技能。

**Token：** AI处理文本的基本单位。中文大约一个字等于1-2个token，英文大约4个字母等于1个token。大部分普通用户不需要关心这个概念。

**文生图（Text-to-Image）：** 用文字描述生成图片的技术。

**图生图（Image-to-Image）：** 基于一张参考图片生成新图片的技术。

**文生视频（Text-to-Video）：** 用文字描述生成视频的技术。

**图生视频（Image-to-Video）：** 基于一张静态图片生成动态视频的技术。

**AI绘画：** 用AI生成图片的过程，也叫AIGC（AI Generated Content）。

**AIGC：** AI Generated Content，AI生成内容。包括AI写的文字、画的图、做的视频、生成的音乐等。

**API：** Application Programming Interface，应用程序接口。简单说就是让不同的软件之间可以互相调用功能。你作为普通用户不需要直接使用API，但有些工具提供API接口让开发者调用。

**开源：** 软件的源代码公开，任何人都可以查看、修改和使用。DeepSeek就是开源的。

**部署：** 把软件或模型安装到服务器上，让它可以被访问。

**微调（Fine-tuning）：** 在大模型的基础上，用特定数据训练，让它更擅长某个领域。比如用法律数据微调的模型，回答法律问题会更专业。

**幻觉（Hallucination）：** AI一本正经地说错话，编造不存在的事实。这是大模型的固有问题，目前还没有完全解决。

**上下文（Context）：** AI在处理你的问题时，能"记住"之前对话内容的能力。上下文越长，AI能处理的内容越多。Kimi的超长上下文就是它的核心优势。

**多模态（Multimodal）：** AI能同时处理多种类型的信息，比如文字、图片、音频、视频。

**RAG（检索增强生成）：** AI在回答问题之前，先去检索相关资料，再基于检索到的内容生成回答。这样回答的准确性和时效性会更高。

**智能体（Agent）：** 能自主完成复杂任务的AI系统。比如一个智能体可以帮你规划行程、订机票、订酒店，全程不需要你干预。

**数字人：** AI生成的虚拟人物形象，可以代替真人出镜做视频、直播、演讲。

**扩散模型（Diffusion Model）：** 目前AI生图的主要技术。简单理解就是AI先学习海量图片，然后学会从噪声中还原出图片。你写的提示词就像指南针，告诉AI往哪个方向还原。

**负向提示词（Negative Prompt）：** 告诉AI你不想要什么。比如"不想要模糊、不想要变形的手指"，能大幅提高出图质量。

## 附录M：常见问题补充（50问）

前面已经回答了一些常见问题，这里再补充50个你可能遇到的问题。

### 基础操作类（10问）

**Q1：注册时需要实名认证吗？**

大部分国产AI工具只需要手机号验证即可，不需要实名认证。但如果你要使用付费功能或API，可能需要实名认证。这是平台为了遵守监管要求，正常流程。

**Q2：手机号和电脑可以同时登录吗？**

可以。大部分工具支持多端登录，手机和电脑的数据是同步的。你在手机上发的消息，电脑上也能看到。

**Q3：对话记录会丢失吗？**

正规平台都会保存你的对话记录。但你可以在设置中导出或删除。建议重要的对话及时保存到本地。

**Q4：AI工具需要更新吗？**

手机App会自动更新。网页版不需要手动更新，打开就是最新版。

**Q5：可以用同一个手机号注册多个工具吗？**

可以。每个工具的账号是独立的，互不影响。

**Q6：工具突然用不了了怎么办？**

可能的原因：网络问题、平台维护、账号异常。建议：检查网络、等一会儿再试、查看平台公告。如果是账号问题，联系客服解决。

**Q7：AI生成的内容可以商用吗？**

这取决于具体工具的条款。大部分工具的个人使用免费，商用需要付费或确认条款。建议商用前仔细阅读使用条款。

**Q8：孩子的作业可以用AI做吗？**

AI可以帮助理解题目、讲解思路，但不建议直接抄答案。用AI辅导孩子学习是很好的，但要引导孩子独立思考。

**Q9：AI会记住我的隐私信息吗？**

正规平台不会主动收集或分享你的隐私信息。但建议不要输入敏感信息。具体以各平台的隐私政策为准。

**Q10：免费版和付费版的区别是什么？**

一般来说，免费版有使用额度限制、生成速度较慢、输出质量稍低。付费版无限制或额度更高、速度更快、质量更好、功能更全。对于学习阶段，免费版完全够用。

### 提示词类（10问）

**Q11：提示词有标准格式吗？**

没有绝对的标准格式，但好的提示词通常包含：角色设定 + 具体任务 + 输出要求 + 约束条件。越具体越好。

**Q12：提示词越短越好还是越长越好？**

取决于需求。简单问题用短提示词，复杂任务用长提示词。关键是信息量，不是字数。

**Q13：AI能记住之前的对话吗？**

能，但有上下文长度限制。对话太长的话，AI会"忘记"最开始的内容。Kimi的上下文最长，可以处理几十万字。

**Q14：同一个问题问不同AI，答案不一样怎么办？**

这是正常的，不同模型有不同的训练数据和偏好。对于重要信息，建议用多个工具交叉验证，或者自己核实。

**Q15：AI说它不确定的时候，还能信吗？**

AI说"不确定"通常比编造答案更可信。你可以追问细节，或者换一个方式问同样的问题。

**Q16：可以让AI一直追问我吗？**

可以，你可以在提示词里要求AI"如果信息不足，请追问"。但大多数AI默认是直接回答，不会主动追问。

**Q17：AI能理解方言吗？**

部分工具可以，比如讯飞星火对普通话的理解最好。其他工具对标准普通话的理解都不错，但对方言的支持有限。

**Q18：可以用AI生成的内容直接发表吗？**

不建议。AI生成的内容需要人工审核和修改，特别是公开发布的内容。建议把AI输出当作草稿，自己润色后再使用。

**Q19：AI能实时联网吗？**

部分工具支持联网搜索（如Kimi、文心一言、豆包），能获取最新信息。不联网的工具只能基于训练数据回答，时效性有限。

**Q20：AI能处理图片中的文字吗？**

可以，这叫OCR（光学字符识别）。Kimi、讯飞星火等工具支持上传图片并识别其中的文字。DeepSeek也支持多模态输入。

### 生图类（10问）

**Q21：AI生成的图片有版权吗？**

目前法律还在完善中。大部分平台允许个人使用，商用需要查看具体条款。建议保留生成记录作为凭证。

**Q22：AI生成的人物看起来不自然怎么办？**

在提示词中加入更具体的外貌描述，并使用负面提示词排除"变形、扭曲、不自然"等问题。多生成几次，选最好的。

**Q23：AI生成的图片分辨率不够怎么办？**

在提示词中加入"8K、超高清、高分辨率"等画质词。或者使用工具自带的超分辨率功能放大图片。

**Q24：怎么让AI生成的角色在多张图中保持一致？**

方法一：先生成一张角色参考图，后续用图生图上传参考图。方法二：在堆友或LiblibAI训练专属模型。方法三：使用风格参考功能。

**Q25：AI生图的风格怎么控制？**

在提示词末尾加上风格词，如"写实风格"、"动漫风格"、"水墨画风格"、"油画风格"。也可以上传风格参考图。

**Q26：负面提示词填什么？**

通用负面提示词：模糊、低质量、水印、文字、扭曲、变形、丑陋、畸形、残缺、低分辨率、压缩痕迹。

**Q27：AI生图一次生成多少张？**

大部分工具一次生成4张（如即梦），有些工具可以调整数量（如通义万相可以一次生成更多）。

**Q28：AI生成的图有水印怎么办？**

大部分国产工具免费版可能有小水印，付费后可以去除。下载时选择无水印选项。

**Q29：AI能生成透明背景的图片吗？**

部分工具支持（如可灵的抠图功能、美图AI的抠图功能）。生成后也可以用在线抠图工具去除背景。

**Q30：AI生图的提示词用中文还是英文？**

国产工具用中文效果最好，英文提示词在国产工具上不一定更好。海外工具（如Midjourney）用英文效果更好。

### 视频类（10问）

**Q31：AI生成的视频最长能有多长？**

大部分AI视频工具一次生成2-10秒。长视频需要多段拼接或使用视频续写功能。白日梦可以生成长达50分钟的视频。

**Q32：AI视频和实拍视频的区别大吗？**

2026年的AI视频质量已经很高，但在细节、运动自然度、人物表情等方面与实拍仍有差距。不过对于短视频、社交媒体内容来说，已经足够用。

**Q33：AI视频怎么配音？**

在剪映中使用"文本朗读"功能，输入文案选音色即可。也可以单独用讯飞配音等工具生成配音文件，再导入剪辑软件。

**Q34：AI视频可以加字幕吗？**

剪映的"智能字幕"功能可以自动识别语音生成字幕，准确率很高。

**Q35：AI视频怎么配背景音乐？**

剪映内置音乐库，可以根据视频风格推荐音乐。也可以单独用海绵音乐等工具生成原创配乐。

**Q36：AI生成的人物为什么会变形？**

AI视频生成对人体的理解还不够完美，特别是在复杂动作时。建议用更具体的提示词描述动作，或者降低运动强度。

**Q37：可灵的运动笔刷怎么用？**

在可灵的专业模式中，上传图片后用画笔在画面上涂抹，指定这个区域的运动方向和强度。比如画在水面上让水流动。

**Q38：Vidu的人物一致性怎么用？**

上传角色的多角度参考图，Vidu会记住角色的外观特征，生成视频时保持面部一致。适合做有剧情的连续视频。

**Q39：AI视频导出的格式是什么？**

大部分工具导出MP4格式，这是最通用的视频格式，可以在任何平台播放。分辨率建议至少1080P。

**Q40：AI视频能赚钱吗？**

能。短视频带货、自媒体流量变现、接广告、做代运营都是可行的变现方式。但需要时间积累，不是一夜暴富的事。

### 变现类（10问）

**Q41：新手第一个月能赚多少钱？**

第一个月通常赚不了多少钱，主要是学习和积累。第二到三个月开始有收入，月入1000-3000是合理预期。第六个月月入3000-10000是可达成的目标。

**Q42：AI变现需要投入多少钱？**

初期不需要投入，所有工具有免费版。开始变现后，可能需要付费升级工具，每月50-100元的投入足够。

**Q43：AI头像定制怎么定价？**

新手定价30-50元/张，有一定经验后可以涨到80-150元/张。批量订单可以优惠。

**Q44：在哪里接AI设计的单？**

淘宝、闲鱼、猪八戒、站酷、小红书、抖音、即刻。最好的获客渠道是小红书和抖音，发作品展示你的AI能力。

**Q45：AI副业需要营业执照吗？**

个人接单不需要营业执照。但如果要开店或大量收款，建议注册个体户。具体咨询当地工商部门。

**Q46：AI副业一天需要花多少时间？**

初期每天1-2小时足够。熟练后可以提高到3-4小时。不建议超过6小时，AI的优势就是效率高，不需要拼时间。

**Q47：AI副业会不会不稳定？**

初期可能不稳定，但随着口碑积累会越来越稳定。建议多渠道获客，不要只依赖一个平台。

**Q48：AI副业能当主业吗？**

可以，但建议先兼职做，等月收入稳定超过主业工资后再考虑全职。给自己留6个月的过渡期。

**Q49：AI副业有什么风险？**

主要风险是平台政策变化和市场竞争。建议：多平台布局、建立自己的客户群、持续学习提升技能。

**Q50：最推荐的AI变现方向是什么？**

2026年最推荐的三个方向：AI短视频代运营（需求最大）、AI设计接单（门槛较低）、AI内容创作（可持续性最强）。建议根据自己的兴趣和特长选择。
