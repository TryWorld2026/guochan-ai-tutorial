## 二、提示词黄金公式

**好的提示词 = 角色 + 任务 + 格式 + 约束**

示例：你是一位资深的文案专家（角色），帮我写一段奶茶店推广文案（任务），请用列表的方式呈现（格式），语气要活泼可爱，不要用专业术语（约束）。

**常用角色：** 你是一位专业的XX专家 / 你是一位耐心的老师 / 你是一位资深的程序员

**常用格式：** 请用列表/表格/分步骤的方式回答 / 请控制在200字以内

**常用语气：** 语气要正式/轻松/专业/亲切/热情

## 四、常见问题速查

**Q：AI工具要钱吗？** 所有推荐的工具都有免费版，学习阶段完全够用。

**Q：需要编程吗？** 前8章完全不需要，第5章是AI帮你写代码。

**Q：需要美术基础吗？** 不需要，会写提示词就行。

**Q：每天需要学多久？** 每天1-2小时，一个月入门，三个月熟练。

**Q：AI会犯错吗？** 会。重要信息一定要人工核实。

**Q：AI生成的内容可以商用吗？** 大部分需要付费才能商用，免费版只能个人使用。
